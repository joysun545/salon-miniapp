# 美容院预约微信小程序

在微信开发者工具导入仓库并编译，首页默认为「美容护理」。小程序调用 `https://joytest.site/salon/api`，服务器需按 [后端仓库](https://github.com/joysun545/salon-api/tree/feat/booking-mvp) 的四角色联调步骤启动。

1. 从首页进入管理员后台，输入服务器配置的管理员令牌，添加未来可接待排班。首页自带两个演示项目，可新增或编辑项目、发布面向游客或顾客的活动。
2. 回到首页，选择项目或活动并模拟支付。进入「我的服务」选择可约时段并提交预约。
3. 从首页进入店员工作台，以店员令牌刷新任务并接单。到预约时间后确认服务完成。
4. 在「我的服务」刷新预约状态并确认完成，检查流水中的已核销次数。管理员也可刷新后台查看任务状态。

联调支付不收款，顾客会话保存在当前设备。本项目保留原预约页面供旧流程使用。真机使用正式 AppID 时，请把 `https://joytest.site` 加入 request 合法域名。
