# 美容院预约微信小程序

本地联调版，可选择护理和时段、提交预约，并在门店确认后刷新查看状态。当前设备保留最近一笔预约。

1. 在运行微信开发者工具的电脑上，按 [后端仓库](https://github.com/joysun545/salon-api) 的 README 启动 API。
2. 用微信开发者工具导入本仓库，使用测试号或在本地设置自己的 AppID。联调配置允许访问同机的 `http://127.0.0.1:3000`。
3. 选择护理和时段并提交。按后端 README 用店员接口确认，再回到小程序点击「刷新预约状态」。

联调只使用演示数据。真机和正式发布需要配置可访问的 HTTPS API 和小程序合法请求域名。
